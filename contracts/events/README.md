# Контракты событий Kafka

Здесь будут схемы событий об уже произошедших изменениях, которые публикуют сервисы-владельцы данных.

- Назначение события, его источник и структура полезной нагрузки.
- Идентификаторы события и сущности, версии схемы и сущности.
- События обновления и удаления для построения проекций, включая локальную проекцию ИИ.
