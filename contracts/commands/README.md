# Контракты команд Kafka

Здесь будут схемы команд на изменение данных. У каждой команды один сервис-владелец, который проверяет права и бизнес-правила при выполнении.

- Назначение команды, её получатель и структура полезной нагрузки.
- Идентификаторы сообщения и операции, версия схемы, контекст инициатора.
- Правила идемпотентности и связь команды со статусом выполнения.
