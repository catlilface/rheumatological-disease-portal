# Как меняется результат скрининга

У одного прохождения анкеты один результат. Версия вопросов и правила подсчёта фиксируются в момент старта: если анкету обновят позже, ваше прохождение не будет пересчитано по новым правилам.

**Почему результат может появиться до последнего вопроса?** Если ответ указывает на красный флаг, результат фиксируется сразу, не дожидаясь завершения анкеты. Если вы продолжите отвечать, детали могут уточниться. При этом выявленный красный флаг не исчезнет и уровень результата не понизится.

**Что означает версия результата?** Уточнение добавляет новую версию того же результата. Например, если PDF был подготовлен по версии 1, а после следующих ответов появилась версия 2, уже подготовленный PDF остаётся документом по версии 1. Пояснение ИИ также относится к конкретной версии: если она ещё недоступна, предыдущая не должна выдаваться вместо неё.

**Что происходит при завершении?** После завершения прохождения его итоговый результат больше не меняется. Новое прохождение — другая сессия со своим результатом, а не исправление предыдущего. Результат анкеты не является диагнозом.

Это согласованные правила MVP. Локальный стенд проверяет хранение версий и неизменяемость итога; демонстрационные API пока не выполняют полноценный скрининг и не генерируют PDF или пояснения.
