# Ревматологический портал

Портал разрабатывается для людей, которых беспокоят симптомы возможного ревматологического заболевания. Его задача — помочь человеку описать симптомы и подготовиться к приёму у врача. Скрининг не ставит диагноз и не заменяет консультацию.

В целевом сценарии пользователь заполняет анкету, получает результат с указанием признаков, требующих внимания, и сохраняет его в PDF, чтобы обсудить с врачом. Библиотека материалов и страница «К какому врачу и с чем идти» помогают подготовить вопросы к приёму.
